## Codebase Patterns
- Node.js workspaces used for monorepo (packages/* in root package.json)
- tsconfig.base.json at root; each workspace extends it with `"extends": "../../tsconfig.base.json"`
- Each workspace references `../shared` in tsconfig `references` for project references
- ESLint 9 flat config (eslint.config.mjs) with typescript-eslint
- Root scripts: `npm run typecheck`, `npm run lint`, `npm run format`
- All workspace packages are scoped under `@npmdex/`
- Node.js v24.14.0 (.nvmrc)
- Drizzle ORM for database schema definition and migrations in packages/shared
- Schema defined in `packages/shared/src/schema.ts`, types in `packages/shared/src/types.ts`
- Run `npm run db:generate` in packages/shared to generate migrations, `npm run db:migrate` to apply
- Must run `npm install` at root before `npm run typecheck` (hoisted node_modules)
