## Codebase Patterns
- Node.js workspaces used for monorepo (packages/* in root package.json)
- tsconfig.base.json at root; each workspace extends it with `"extends": "../../tsconfig.base.json"`
- Each workspace references `../shared` in tsconfig `references` for project references
- ESLint 9 flat config (eslint.config.mjs) with typescript-eslint
- Root scripts: `npm run typecheck`, `npm run lint`, `npm run format`
- All workspace packages are scoped under `@npmdex/`
- Node.js v24.14.0 (.nvmrc)
- Drizzle ORM for database schema definition and migrations in packages/shared
- Schema defined in `packages/shared/src/schema.ts`, types in `packages/shared/src/types.ts`
- Run `npm run db:generate` in packages/shared to generate migrations, `npm run db:migrate` to apply
- Must run `npm install` at root before `npm run typecheck` (hoisted node_modules)
- Shared DB connection via `createDb()` from `@npmdex/shared` (uses DATABASE_URL env var)
- Use `onConflictDoUpdate` for upsert patterns with Drizzle ORM
- npm registry APIs: registry.npmjs.org for package info, replicate.npmjs.com/_changes for change feed, api.npmjs.org/downloads for download counts
- Run `npm run format:fix` before committing to fix Prettier formatting
- GitHub API: use `parseGitHubRepo()` from `packages/index-service/src/github.ts` for URL parsing
- index-service CLI flags: `--full-sync`, `--enrich-github`, `--max-packages N`
- TypeScript detection: `detectTypescriptSupport()` from `typescript-detection.ts` — checks native types then DT package existence
- Score service: `npm start` in packages/score-service, supports `--max-packages N`
- Score weights: 40% popularity, 30% maintenance, 30% quality → 0-100 overall
- Redis Stack (redis/redis-stack) in docker-compose.yml; RediSearch enabled by default
- Redis connection via `createRedisClient()` from `@npmdex/shared` (uses REDIS_HOST, REDIS_PORT env vars, defaults to localhost:6379)
- index-service `--build-index` flag populates Redis from PostgreSQL; `--incremental` only re-indexes changed packages
- RediSearch index name: `idx:packages`, key prefix: `pkg:`, JSON documents with full-text on name/description/keywords
- API service: Express on port 3001, `npm start` in packages/api, connects to Redis (not PostgreSQL) for search
- RediSearch `ft.search` returns union type in node-redis v4 — cast result to `{ total: number; documents: Array<...> }`
- Web frontend: React + Vite in packages/web; `npm run dev` starts on port 3000 with proxy to API on 3001
- Web tsconfig uses `moduleResolution: "bundler"` and `module: "ESNext"` (not Node16) for Vite compatibility
- Root lint/format scripts glob `*.{ts,tsx}` to include React files
